## 🚀 How to Use

### Option 1: Open Locally
1. Open `index.html` in any web browser
2. Navigate through all pages using the menu

### Option 2: Deploy Online
You can deploy this website for FREE on:

#### **Vercel** (Recommended - Same as the original site)
1. Go to [vercel.com](https://vercel.com)
2. Sign up with GitHub/Email
3. Click "Add New Project"
4. Upload all files or connect your GitHub repository
5. Click "Deploy"
6. Your website will be live in seconds!

#### **Netlify**
1. Go to [netlify.com](https://netlify.com)
2. Sign up
3. Drag and drop the folder
4. Your site is live!

#### **GitHub Pages**
1. Create a GitHub repository
2. Upload all files
3. Go to Settings → Pages
4. Select branch and save
5. Your site will be live at `username.github.io/repo-name`

## 🔧 Customization

### To Add Gallery Images:
1. Open `gallery.html`
2. Replace placeholder divs with:
```html
<div class="gallery-item">
    <img src="path-to-image.jpg" alt="Description">
</div>
```

### To Update Contact Information:
1. Open `contact.html`
2. Edit the contact details in the contact cards section

### To Change Colors:
1. Open `style.css`
2. Modify the `:root` variables at the top:
```css
--primary-color: #8B5CF6;
--secondary-color: #FF4D9D;
```
